# Trends Agents

AI agents for trend analysis and trend forecasting. See what's trending on Google Trends, TikTok, YouTube and Reddit, and know whether it lasts, right inside Claude, Cursor and ChatGPT.

- **Spot it:** what's rising right now on each platform
- **Judge it:** growth, history and whether it is a spike or a lasting trend
- **Explain it:** the posts, stories and comments behind a trend
- **Use it:** agents for content, ecommerce, market and competitor research
- **Works in** Claude, Cursor, ChatGPT and any MCP client

## Connect

| How | Endpoint |
|---|---|
| MCP with sign-in (Claude, ChatGPT) | `https://trendsagents.com/mcp` |
| MCP with API key | `https://api.trendsagents.com/mcp` |
| REST API | `POST https://api.trendsagents.com/api` |
